# Welesza

Dark fantasy ARPG: przypadkowy podróżnik trafia do Niemiru, osady ukrytej w groźnym lesie. PC, single player, malowane 2D (Dark Painterly), sterowanie myszą inspirowane Diablo 2; wymagająca walka z niewieloma groźnymi przeciwnikami. Silnik: **Godot 4** ([decyzja warunkowa](docs/SILNIK.md)).

Repozytorium zawiera dokumentację projektową: fabułę, postacie, bestiariusz, mechaniki, walkę, mapę świata i grafy poziomów. Pełny spis: [docs/INDEX.md](docs/INDEX.md). Zasady dla agentów: [AGENTS.md](AGENTS.md).
